Depose ici les fichiers de livrables EXPOSABLES PUBLIQUEMENT (PDF, etc.).

Ils sont servis a l'URL : https://ton-domaine/livrables/<nom-du-fichier>

Le clone propose le lien quand une fiche (content/livrables/*.md) avec
"exposable: true" reference ce fichier via le champ "fichier:".

Exemples references par les fiches d'exemple :
- exemple-cahier-charges.pdf  (fiche livrable-01)
- exemple-synthese.pdf        (fiche livrable-03)

Remplace ces placeholders par tes vrais documents anonymises.
